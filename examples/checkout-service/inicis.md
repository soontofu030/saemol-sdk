# KG이니시스와 새몰 SDK

일반결제·빌링·지급대행·외부 도메인·조건부 지급은 별도 계약/승인 범위입니다. SDK가 이런 계약을 대신하지 않습니다. SDK 테스트 키는 PG 테스트 MID 설정과 별개입니다.

유료 live 세션은 승인된 serviceOrigin을 명시합니다. 금액은 새몰 등록 상품/아이템에서 서버가 읽습니다. 비밀키는 판매자 서버에만 보관하고 X-Saemol-Secret으로 요청합니다. 멱등 키는 구매 시도마다 만들고 재요청 시 유지합니다.

웹훅 서명·세션 재조회로 결제를 검증하고 내 DB 트랜잭션에서 중복 적용을 막습니다. 권한 반영 커밋 후 acknowledgeCheckout을 호출합니다. 장애 시 getCheckout으로 복구하고 구매자에게 customerPortal 경로를 제공합니다. 이 흐름의 로컬 테스트는 PG 실승인·송금 검증이 아닙니다.

판매 중단 후 신규 결제와 갱신은 중단하되 지급된 기간/영구 이용권을 임의 소멸시키지 않습니다. 미제공·서비스 종료 시 고객 연락/데이터 내보내기/환급 경로를 유지합니다. 현재 빌링·지급대행·부분 환불·마일스톤 조건부 지급은 계약과 별도 어댑터 검증 전까지 제한됩니다.
